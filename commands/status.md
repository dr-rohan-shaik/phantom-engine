# /phantom:status

Display the current Phantom Engine execution state and progress.

## Usage

```
/phantom:status
```

## Output

Shows:
- Active status
- Current mode (SAFE/AUTO/SANDBOX)
- Current iteration / max iterations
- Current phase
- Task description
- Budget used / total budget
- Verification status
- Deployment status
- Errors and warnings count
- Git branch
- Repository path
